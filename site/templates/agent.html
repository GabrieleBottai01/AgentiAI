Demo agente con tool use

Dai un obiettivo, l'agente decide autonomamente quali tool chiamare. Vedrai ogni passo del loop ReAct (Cap. 3-4-6). Tool disponibili: calculator, current_time, web_search, fetch_url.

Prova:
Loop dell'agente
Premi "Lancia agente" per vedere il loop in azione: thinking → tool call → tool result → ripeti.

Cosa stai vedendo

  1. thinking: l'LLM riceve lo stato e decide se chiamare un tool o rispondere.
  2. tool call: il modello sceglie un tool e produce gli argomenti.
  3. tool result: il backend esegue davvero il tool e ritorna l'output.
  4. Il ciclo continua finché il modello non produce risposta finale o si raggiunge max iterazioni.

Nota: web_search usa l'API gratuita DuckDuckGo Instant Answer, quindi i risultati sono limitati per query troppo specifiche o recenti.
