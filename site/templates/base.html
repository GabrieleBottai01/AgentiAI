API key Anthropic

Per usare le funzionalità AI del sito serve una API key Anthropic tua. La key viene salvata solo nel tuo browser (localStorage) e inviata al backend solo per inoltrare la richiesta a Anthropic. Non viene mai loggata né persistita lato server.

Crea una key gratuitamente su console.anthropic.com (sezione "API Keys").

Suggerimento: imposta un budget limit mensile sulla console Anthropic (es. €10) per evitare sorprese.
